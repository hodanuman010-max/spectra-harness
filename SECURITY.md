# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

SpectraHarness is an open-source evaluation and red-teaming tool designed to improve AI safety and robustness. If you discover a security vulnerability in the SpectraHarness code itself (e.g. remote code execution in adapters, server exploits), please report it responsibly.

### Responsible Disclosure Process
1. Do not open a public issue on GitHub for unpatched security vulnerabilities.
2. Email your vulnerability report to `security@spectraharness.org` or open a confidential Security Advisory on GitHub.
3. Include detailed steps to reproduce the issue.
4. The maintainers will respond within 48 hours to confirm receipt and provide an estimated remediation timeline.
